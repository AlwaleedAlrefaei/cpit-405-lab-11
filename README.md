# CPIT-405 Lab 11

Open a terminal in this folder and run `php -S localhost:8000`.
Visit http://localhost:8000, open Developer Tools > Console, then click Load Data.
The data.php endpoint returns the two student records in JSON format.
Submit index.html, script.js and data.php. The JS file contains the student name and ID.
The separate project homework requires integration into the existing project and is not included.
